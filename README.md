# Sbor — iPhone-приложение для поиска событий и общения

Демонстрационный прототип для поиска локальных мероприятий и общения участников в Новосибирске.

| | |
|---|---|
| **Платформа** | iOS 17 и выше |
| **Технологии** | SwiftUI, MapKit, UserDefaults |
| **Внешние зависимости** | нет |
| **Версия документа** | 1.0 от 30 октября 2026 года |

> Прототип подготовлен для учебной презентации. Он показывает интерфейс и основные сценарии, но не заменяет полноценную систему с сервером, регистрацией и авторизацией.

---

## Возможности

| Раздел | Что реализовано | Что даёт пользователю |
|---|---|---|
| **События** | Демо-события Новосибирска, поиск, категории, карточка события | Быстрый поиск подходящей встречи |
| **Карта** | Метки событий, схема, спутниковый слой, подписи источников | Понятно, где проходит событие |
| **Мессенджер** | Общая лента, публикации, комментарии, личные диалоги | Открытое общение со всеми участниками |
| **Профиль** | Имя, город, мои события, статус демо-режима | Видна текущая роль и состояние прототипа |
| **Стиль** | Материалы iOS, коралловая и мятная палитра, скруглённые карточки | Единый современный iOS-интерфейс |

### Пользовательские сценарии

- Найти событие по названию или по категории.
- Открыть карточку события, посмотреть место и время, присоединиться к встрече.
- Посмотреть карту Новосибирска с метками мероприятий.
